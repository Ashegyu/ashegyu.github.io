API Usage Meter

An unofficial Android app to check your organization's API usage, cost and credit balance with an Admin API key

  • Today's and this month's API cost and token usage by model
  • Daily charts for the last 7/30 days and today's hourly chart
  • Estimated balance (your entered credit balance minus later spend) with low-balance alerts
  • Home screen widget · Korean and English

Your Admin API key is encrypted on the device with Android Keystore and sent only to the API provider's official server over HTTPS.

API 사용량 미터

Admin API 키로 조직의 API 사용량·비용·크레딧 잔액을 Android에서 확인하는 비공식 앱

  • 오늘·이번 달 API 비용과 모델별 토큰 사용량
  • 최근 7일/30일, 오늘 시간별 차트
  • 입력한 크레딧 잔액에서 사용 비용을 빼 추정 잔액 표시, 기준 이하 시 알림
  • 홈 화면 위젯 · 한국어/영어 지원

Admin API 키는 기기 안에서 Android Keystore로 암호화해 보관하며, API 제공사의 공식 서버(HTTPS) 외에는 어디에도 보내지 않습니다.
