API Usage Meter

An unofficial Android app to check your Claude API usage, cost and credit balance with an Anthropic Console Admin API key

  • Today's and this month's API cost with change vs. yesterday and last month, and token usage by model
  • Estimated balance (your entered credit balance minus later spend), run-out date and month-end forecast
  • Daily charts for the last 7/30 days and today's hourly chart
  • Cost by API key, workspace, product and service tier; cost composition with caching and discount savings
  • API key list with deactivate/reactivate; view rate limits and set per-workspace limits
  • Alerts for low balance, monthly/daily budgets and spending spikes
  • Home screen widget · Korean and English

Your Admin API key is encrypted on the device with Android Keystore and sent only to Anthropic's API (api.anthropic.com) over HTTPS. The app only changes your organization when you deactivate or reactivate an API key yourself and confirm it.

API 사용량 미터

Anthropic Console Admin API 키로 Claude API 사용량·비용·크레딧 잔액을 Android에서 확인하는 비공식 앱

  • 오늘·이번 달 API 비용과 어제·지난달 대비 증감률, 모델별 토큰 사용량
  • 입력한 크레딧 잔액에서 사용 비용을 빼 추정 잔액 표시, 소진 예상일과 월말 예상 비용
  • 최근 7일/30일, 오늘 시간별 차트
  • API 키·워크스페이스·제품·서비스 티어별 비용, 캐시·할인 절감액이 보이는 비용 구성
  • API 키 목록과 비활성화·재활성화, Rate limit 확인과 워크스페이스별 한도 설정
  • 잔액 부족, 월·일 예산, 지출 급증 알림
  • 홈 화면 위젯 · 한국어/영어 지원

Admin API 키는 기기 안에서 Android Keystore로 암호화해 보관하며, Anthropic API(api.anthropic.com, HTTPS) 외에는 어디에도 보내지 않습니다. 앱이 조직 설정을 바꾸는 것은 사용자가 직접 API 키를 비활성화·재활성화하고 확인했을 때뿐입니다.
