Privacy Policy

App: API Usage Meter (package io.github.ashegyu.usagemeter) · Effective: November 23, 2026

API Usage Meter (the "App") is made by AsheGyu, an individual developer (the "Developer"). This policy explains what information the App handles and what information the Google AdMob ads in the App collect.

1. Information the Developer collects

None. The Developer runs no server and does not receive or store your Admin API key, usage or cost data, or settings.

2. Information stored only on your device

ItemHow it is storedPurpose
Anthropic Admin API keyEncrypted storage backed by Android Keystore (EncryptedSharedPreferences)Reading your organization's usage and cost from the Anthropic API
Credit balance and the time you entered it, alert threshold, display settingsApp-private storageEstimating your balance and sending low-balance alerts
Last fetched results (today's cost, estimated balance)App-private storageShowing the home screen widget

This information is excluded from device backups (cloud backup and device-to-device transfer). It is deleted when you delete the key in the App or uninstall the App.

3. Information sent to Anthropic

To read usage, your Admin API key is sent over HTTPS only to api.anthropic.com. Anthropic's privacy policy applies to those requests and responses: https://www.anthropic.com/legal/privacy

4. Advertising (Google AdMob)

The App is free and shows Google AdMob banner ads. For advertising, Google may collect and process:

  • Device identifiers such as the Android Advertising ID
  • IP address and the approximate location derived from it
  • Device, operating system and app information
  • Ad interactions such as impressions and clicks, and diagnostics used to prevent invalid traffic

This information is used to serve and measure ads, prevent fraud and, if you consent, personalize ads. It is processed under Google's policies: Google Privacy Policy, How Google uses information from sites or apps that use its services.

In regions that require consent, such as the European Economic Area (EEA), the UK and Switzerland, the App asks for consent through Google's User Messaging Platform (UMP) when it starts. You can change your choice at any time in the App under Settings → "Ad privacy settings". Any user can reset or delete the advertising ID in Android Settings → Privacy → Ads.

5. Sharing with third parties

The Developer does not sell or share your information with third parties. No information is sent anywhere other than Anthropic (for usage lookups) and Google (for ads) as described above.

6. Children

The App is a tool for Anthropic Console organization administrators and is not directed to children (under 13, or under 14 in Korea).

7. Security

All communication uses HTTPS only, and the full Admin API key is never shown on screen or written to logs. No method is perfectly secure, so we recommend creating a dedicated Admin key for this App with an expiration date, and deleting the key in the Anthropic Console right away if you lose your device.

8. Changes to this policy

If this policy changes, this page will be updated along with its effective date.

Deleting your data

See Delete your data for step-by-step instructions.

앱: API 사용량 미터 (패키지 io.github.ashegyu.usagemeter) · 시행일: 2026년 11월 23일

API 사용량 미터(이하 "앱")는 개인 개발자 AsheGyu(이하 "개발자")가 만든 앱입니다. 이 방침은 앱이 어떤 정보를 다루는지, 그리고 앱에 포함된 Google AdMob 광고가 어떤 정보를 수집하는지 설명합니다.

1. 개발자가 수집하는 정보

없습니다. 개발자는 서버를 운영하지 않으며, 사용자의 Admin API 키, 사용량·비용 데이터, 설정값을 받거나 저장하지 않습니다.

2. 기기 안에만 저장되는 정보

항목저장 방식용도
Anthropic Admin API 키Android Keystore 기반 암호화 저장소(EncryptedSharedPreferences)Anthropic API에서 조직 사용량·비용 조회
사용자가 입력한 크레딧 잔액·입력 시각, 알림 기준 금액, 화면 설정앱 전용 저장소추정 잔액 계산, 잔액 부족 알림

이 정보는 기기 백업(클라우드 백업, 기기 간 이전)에서 제외됩니다. 앱에서 키를 삭제하거나 앱을 삭제하면 함께 지워집니다.

3. Anthropic으로 전송되는 정보

사용량 조회를 위해 Admin API 키는 HTTPS로 api.anthropic.com에만 전송됩니다. 이 요청과 응답에는 Anthropic의 개인정보처리방침이 적용됩니다: https://www.anthropic.com/legal/privacy

4. 광고 (Google AdMob)

앱은 무료로 제공되며 Google AdMob 배너 광고를 표시합니다. 광고를 위해 Google이 다음 정보를 수집·처리할 수 있습니다.

  • 광고 ID(Android Advertising ID) 등 기기 식별자
  • IP 주소 및 이를 통한 대략적인 위치
  • 기기·운영체제 정보, 앱 정보
  • 광고 노출·클릭 등 상호작용 정보, 비정상 트래픽 방지를 위한 진단 정보

이 정보는 광고 제공·성과 측정·부정 행위 방지 및 (동의한 경우) 맞춤형 광고에 쓰이며, Google의 정책에 따라 처리됩니다: Google 개인정보처리방침, Google 파트너 사이트에서의 데이터 사용.

유럽경제지역(EEA)·영국·스위스 등 동의가 필요한 지역에서는 앱 실행 시 Google의 동의 관리 도구(UMP)로 동의를 받으며, 앱의 설정 화면 → "광고 개인정보 설정"에서 언제든 바꿀 수 있습니다. 모든 사용자는 Android 설정 → 개인정보 보호 → 광고에서 광고 ID를 재설정하거나 삭제할 수 있습니다.

5. 제3자 제공

개발자는 사용자 정보를 판매하거나 제3자에게 제공하지 않습니다. 위의 Anthropic(사용량 조회)과 Google(광고) 외에 정보가 전송되는 곳은 없습니다.

6. 아동

앱은 Anthropic Console 조직 관리자를 위한 도구이며 만 14세 미만 아동을 대상으로 하지 않습니다.

7. 보안

모든 통신은 HTTPS로만 이루어지며, Admin API 키는 화면·로그에 전체가 표시되지 않습니다. 다만 어떤 방법도 완전한 보안을 보장하지는 않으므로, 이 앱 전용 Admin 키를 만들고 만료일을 설정하며, 기기를 분실한 경우 Anthropic Console에서 키를 즉시 삭제하시길 권장합니다.
