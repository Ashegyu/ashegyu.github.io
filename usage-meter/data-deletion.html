Delete your data

App: API Usage Meter (io.github.ashegyu.usagemeter) · Developer: AsheGyu

The developer runs no server and does not store any of your data, so there is nothing to delete on our side. All app data lives only on your device, and you can delete it yourself at any time.

Delete the data stored on your device

  1. Open API Usage Meter → Settings.
  2. Under API & data, tap Delete key and confirm. This deletes your Admin API key, cached results and stops background checks. (In demo mode the button is Exit demo.)
  3. To delete everything else (entered balance, alert threshold, display settings), uninstall the app, or go to Android Settings → Apps → API Usage Meter → Storage → Clear storage.

This data is deleted immediately and is not kept anywhere else. The app excludes it from Google cloud backups and device transfers.

Email worbswo@naver.com with the subject "API Usage Meter data deletion". Since we hold no data, we'll reply with these steps within 7 days.

데이터 삭제 안내

앱: API 사용량 미터 (io.github.ashegyu.usagemeter) · 개발자: AsheGyu

개발자는 서버를 운영하지 않으며 사용자의 데이터를 보관하지 않습니다. 그래서 개발자 쪽에서 지울 데이터는 없습니다. 앱 데이터는 모두 사용자의 기기 안에만 있고, 언제든 직접 삭제할 수 있습니다.

기기에 저장된 데이터 삭제

  1. API 사용량 미터 앱 → 설정을 엽니다.
  2. API 및 데이터에서 키 삭제를 누르고 확인합니다. Admin API 키와 캐시된 조회 결과가 지워지고 백그라운드 확인이 멈춥니다. (데모 모드에서는 버튼이 데모 종료입니다.)
  3. 나머지(입력한 잔액, 알림 기준, 화면 설정)까지 지우려면 앱을 삭제하거나, Android 설정 → 애플리케이션 → API 사용량 미터 → 저장공간 → 데이터 삭제를 누릅니다.

이 데이터는 즉시 삭제되며 다른 곳에 남지 않습니다. 앱은 이 데이터를 Google 클라우드 백업과 기기 간 이전에서 제외합니다.
